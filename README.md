# Своя игра — Telegram-бот по мотивам SIGame

Бот проводит «Свою игру» в групповом чате Telegram: табло с темами и ценами,
кнопка «🔔 Ответить!», особые вопросы, финал со ставками. Играет пакетами
SIGame (`.siq`) — подойдут тысячи готовых пакетов и всё, что собрано в SIQuester.

## Возможности

- **Табло** — inline-клавиатура: темы и цены, сыгранные вопросы гаснут. Выбирает
  тот, кто последним ответил верно; новый раунд начинает отстающий.
- **Кнопка** появляется, когда вопрос «прочитан» (пауза зависит от длины текста).
  Первый нажавший отвечает сообщением в чат. Верно — плюс стоимость и право выбора,
  неверно — минус стоимость, и кнопка снова открывается для остальных.
- **Пас**: рядом с кнопкой — «🙅 Пас» со счётчиком. Когда спасовали все, кто ещё может
  ответить, вопрос сразу закрывается без штрафов и бот показывает ответ. Пас действует
  до конца вопроса, но передумавший игрок может нажать «Ответить!».
- **Особые вопросы** из пакетов SIGame:
  - 🐱 кот в мешке — со сменой темы и выбором цены (`[100;500]`, мин/макс раунда);
  - 💰 вопрос со ставкой — торги по кругу, ва-банк бьётся только бо́льшим ва-банком;
  - 🛡 вопрос без риска — ×2 за верный ответ, без штрафа за неверный;
  - 👥 вопрос для всех и 💰 ставки для всех — тайные ответы в личке;
  - вопросы с вариантами ответа и числовые с допуском (формат SIGame 5).
- **Финал** — участники с плюсовым счётом по очереди убирают темы, делают тайные
  ставки и отвечают в личке боту.
- **Ведущий**: бот (проверка с учётом опечаток, падежей, «неверных» вариантов автора
  пакета и апелляцией с голосованием игроков) или человек — ему в личку приходят
  правильные ответы и кнопки «✅ Верно / ❌ Неверно».
- **Медиа**: картинки, аудио, видео, ссылки; медиа после маркера показывается вместе
  с ответом. Каждый файл загружается в Telegram один раз, дальше — по `file_id`.
- **Пакеты**: встроенные (папка `packages/`) и свои — отправьте `.siq` в чат во время
  набора игроков. Поддерживаются форматы SIGame версий 3–5.
- Темп (быстрый/обычный/медленный), `/skip`, `/kick`, `/setscore`, темы форумов,
  несколько игр в разных чатах одновременно.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Разрешите боту читать сообщения в группах — по ним он принимает ответы:
   `@BotFather → /mybots → бот → Bot Settings → Group Privacy → Turn off`
   (после смены настройки удалите бота из группы и добавьте заново).
   Вместо этого можно просто сделать бота админом группы.
3. Скопируйте настройки и впишите токен в `BOT_TOKEN`:

```bash
cp .env.example .env
```

4. Установите зависимости (нужен Python 3.11+) и запустите:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

```bash
.venv/bin/python -m sibot
```

Или через Docker:

```bash
docker build -t sigame-bot . && docker run -d --env-file .env -v "$PWD/data:/app/data" sigame-bot
```

## Как играть

1. Добавьте бота в группу и напишите `/newgame`.
2. Игроки жмут «🙋 Играть». Тех, кто ещё не писал боту, Telegram сам перебросит к нему
   в личку — достаточно нажать «Старт» (в личке бот принимает ставки и ответы финала).
3. По желанию: «🎙 Стать ведущим», «📦 Пакет», темп, апелляции.
4. Создатель лобби (или админ чата) жмёт «▶️ Начать».

| Команда | Что делает |
|---|---|
| `/newgame` | новая игра в группе |
| `/join`, `/leave` | войти в игру (можно и во время игры) / выйти |
| `/score` | счёт и номера игроков |
| `/skip` | пропустить вопрос (ведущий, создатель, админ) |
| `/kick N`, `/setscore N сумма` | убрать игрока, поправить счёт (то же; можно реплаем) |
| `/stop` | остановить игру |
| `/help` | правила |

## Пакеты

- `packages/demo` — встроенный демо-пакет: разминка, основной раунд со всеми особыми
  вопросами, финал. Это обычный распакованный пакет — его удобно читать и править.
- Положите в `packages/` любые `.siq` (или папки с `content.xml`) — они появятся
  в меню «📦 Пакет» после перезапуска.
- Свой пакет можно прислать файлом в чат во время набора игроков. Облачный Bot API
  отдаёт ботам файлы только до 20 МБ; для больших пакетов с видео поднимите
  [локальный Bot API сервер](https://github.com/tdlib/telegram-bot-api) и укажите
  `BOT_API_URL` и `BOT_API_LOCAL=true` в `.env`.
- Создавать пакеты удобно в SIQuester из [репозитория SIGame](https://github.com/VladimirKhil/SI).

## Устройство

```
sibot/
  siq/        модель пакета и парсер .siq (форматы 3–5, %-кодированные имена файлов)
  game/
    session.py  лобби и сценарий игры одной корутиной; действия игроков — через submit()
    checker.py  автопроверка ответов
    timings.py  тайминги и пресеты темпа
  tg/         aiogram: обработчики, тексты/клавиатуры, отправка медиа, повтор при 429
  library.py  встроенные и загруженные пакеты, кэш file_id
  registry.py активные игры (одна на чат)
```

Сценарий игры — обычная асинхронная функция: «показать табло → ждать выбора → показать
вопрос → ждать нажатия…». Нажатия проверяются синхронно, поэтому из двух одновременных
«Ответить!» засчитывается ровно одно, а устаревшие кнопки не срабатывают.

## Тесты

```bash
.venv/bin/pip install -r requirements-dev.txt && .venv/bin/python -m pytest
```

Тесты гоняют настоящий диспетчер aiogram и игровой движок поверх фейкового Telegram:
лобби, все типы вопросов, апелляции, финал, ведущего-человека, загрузку `.siq` и
несколько полных случайных партий по демо-пакету. Парсер проверен на эталонных
пакетах SIGame.

## Ограничения

- Состояние игр хранится в памяти: при перезапуске бота идущие игры прерываются.
- Telegram разрешает боту ~20 сообщений в минуту в одной группе. Бот экономит
  сообщения (ответ и табло — одним сообщением), а при превышении лимита ждёт и повторяет.
- Сложные «сценарии» вопросов SIGame 5 (`script`) упрощаются до показа контента.
